# Desafío IA · Feria de Primavera

Juego de preguntas sobre Inteligencia Artificial para la feria de la universidad.
Se elige una de las 6 carreras y salen 5 preguntas al azar (de 15 por carrera). Con 5 de 5, pantalla de premio.

- Sitio estático: `index.html`, `styles.css`, `app.js`, sin build.
- Las preguntas están en `questions.js` (`a` = correcta, `w` = incorrectas; el orden se mezcla solo).
- Probar local: `python3 -m http.server` y abrir http://localhost:8000
- Deploy: Vercel (proyecto `primavera26199`).
